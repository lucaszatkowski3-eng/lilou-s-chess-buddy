# Lilou's Chess Buddy

Erstelle eine Schach Ki für meine kleine Schwester Lilou auf der Startseite soll ein animierter Charakter sein den sie mit Punkten Füttern muss und sie kann zusätzlich mit diesen Punkten neue Kleidung oder Schmuck kaufen für den character er soll sich auf ein Tier beziehen aber auch Bezug zu Schach haben und die Punkte soll sich durch Schachpartien bekommen desto besser sie war desto mehr Punkte gibt es und ich möchte das der Charakter auch bei guten Zügen lobt und bei schlechteren Tipps gibt aber es sollen nicht immer die gleichen Aussagen sein der Charakter darf pro Spiel jedes Lob maximal 2 mal sagen/schreiben und wenn sie besser wird soll der bot auch besser werden
